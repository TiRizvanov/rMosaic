# Package index

## Core Functions

Main visualization functions

- [`mosaic()`](https://tirizvanov.github.io/rMosaic/reference/mosaic.md)
  : Render a Mosaic visualization in Shiny
- [`mosaicOutput()`](https://tirizvanov.github.io/rMosaic/reference/mosaicOutput.md)
  : Shiny output for Mosaic widget
- [`renderMosaic()`](https://tirizvanov.github.io/rMosaic/reference/renderMosaic.md)
  : Shiny render function for Mosaic

## Helper Apps

Shiny helper applications

- [`runMosaicApp()`](https://tirizvanov.github.io/rMosaic/reference/runMosaicApp.md)
  : Run a Mosaic Shiny App in the RStudio Viewer
- [`runMosaicWithExport()`](https://tirizvanov.github.io/rMosaic/reference/runMosaicWithExport.md)
  : Run a Mosaic Shiny App with selection export
- [`runMosaicExport()`](https://tirizvanov.github.io/rMosaic/reference/runMosaicExport.md)
  : Run a Mosaic app and export brush/query selections back to R

## Selection Retrieval

Retrieve selections exported from interactive apps

- [`get_mosaic_selection()`](https://tirizvanov.github.io/rMosaic/reference/get_mosaic_selection.md)
  : Retrieve a stored Mosaic selection
- [`list_mosaic_selections()`](https://tirizvanov.github.io/rMosaic/reference/list_mosaic_selections.md)
  : List all stored Mosaic selections
